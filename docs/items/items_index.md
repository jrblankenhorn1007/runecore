# Items Index

Every catalog entity is documented as one item per Markdown file below a category folder. Catalog files are navigation indexes only.

## Categories

- [Weapons](weapons/weapons_index.md): melee, ballistic, energy, magic, and shields.
- [Armor](armor/armor_index.md): head, chest, legs, footwear, and armor-type folders.
- [Accessories](accessories/): rings, earrings, necklaces, pendants, relics, and anklets.
- [Consumables](consumables/): food, beverages, potions, medicine, mutagens, scrolls, and combat stims.
- [Materials](materials/): crystals, ores, monster parts, salvage, textiles, woods, and exotics.
- [Tools](tools/): harvesting and utility tools.

## Required Entity Metadata

Every item dossier contains `Stable ID`, `Entity type`, `Category`, `Implemented`, `Implementation`, `Asset generated`, `Asset`, and `Source catalog` fields. Generated images remain under `assets/generated/` and are linked from the dossier; they are not copied into `docs/`.
