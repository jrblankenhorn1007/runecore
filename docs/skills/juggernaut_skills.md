# Juggernaut Class Skill Tree: Heavy Armor, Kinetic Shields & Siegesmithing

This document specifies all 52 class skills for the **Juggernaut (Warrior Archetype)** in Untitled RPG. The Juggernaut specializes in overwhelming physical mass, frontal damage mitigation, fortress anchoring, and catastrophic seismic devastation.

---

## 1. Class Identity & Resource Dynamics
- **Core Resource**: Kinetic Impact Charge ($KIC$, 0–100 scale). Generated by absorbing incoming enemy damage, blocking with shields, and smashing heavy two-handed warhammers into terrain or foes.
- **Role**: Frontline anchor, crowd-control juggernaut, heavy ordnance siege specialist.
- **Weapon Proficiencies**: Greatswords, Colossal Hammers, Tower Shields, Heavy Shotguns, Autocannons.
