# Warden Class Skill Tree: Holy Retribution, Radiant Aegis, Oaths & Blessed Armaments

This document specifies all 52 class skills for the **Warden (Paladin Archetype)** in Untitled RPG. The Warden stands as an inviolable holy crusader, shielding party members with luminous auras, crushing the wicked with sacred warhammers, binding demonic entities in consecrated chains, and swearing divine oaths.

---

## 1. Class Identity & Resource Dynamics
- **Core Resource**: Holy Fervor ($FRV$, 0–100 scale). Builds by blocking enemy strikes with shields, standing fast within consecrated ground, and striking down blasphemous horrors.
- **Oath Mechanics**: Wardens select one active Divine Oath that fundamentally alters their offensive, defensive, or supportive stance.
- **Weapon Proficiencies**: Blessed Warhammers, Halberds, Holy Greatswords, Tower Shields, Radiant Relics.
