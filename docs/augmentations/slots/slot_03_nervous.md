# Slot 3: Nervous System Augmentations Catalog (24 Augmentations)

## 1. Mechanics of the Nervous System Slot
- **Slot Capacity**: 1 Nervous System Augmentation installed along the spinal column.
- **Role**: Governs reflexes, attack and movement speeds, stamina and mana flow, and emergency adrenaline triggers.
