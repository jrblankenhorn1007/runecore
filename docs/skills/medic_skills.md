# Medic Class Skill Tree: Field Surgery, Radiant Auras, Cellular Restoration & Toxins

This document specifies all 52 class skills for the **Medic (Cleric Archetype)** in Untitled RPG. The Medic blends high-tech cellular engineering, field trauma surgery, holy radiant frequencies, combat resuscitation, and biochemical hazard warfare.

---

## 1. Class Identity & Resource Dynamics
- **Core Resource**: Bio-Triage Stock ($BTS$, 0–100 scale). Generated by administering healing to self or companions, analyzing fallen samples, and cleansing negative status effects.
- **Role**: Supreme combat sustain, party lifeline, debuff cleansing, radiant holy smiting.
- **Weapon Proficiencies**: Syringe Injectors, Chemical Spray Guns, Holy Scepters, Defibrillator Pads, Flails.

---

## 2. Complete Medic Skill Catalog (52 Skills)
