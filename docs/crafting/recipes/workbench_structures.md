# Workbench Recipes: Structures, Furniture, Tools & Basic Gear

This document specifies all 85 crafting recipes for the Basic Workbench, Carpenter's Desk, and Scavenger's Table in Untitled RPG.

---

## 1. Station Mechanics & Requirements
- **Station Object**: Basic Wooden Workbench (crafted by hand from 10x Scrap Wood).
- **Proximity Requirement**: Player must be within 4 tiles of the workbench to access these blueprints.
- **Crafting Time**: Instant (0.0 seconds). Materials are deducted immediately upon selection.
