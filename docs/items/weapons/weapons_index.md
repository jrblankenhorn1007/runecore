# Weapons Documentation

Weapons are grouped by combat category, then by family. Every weapon has a dedicated Markdown dossier named after the weapon; stable IDs remain inside each dossier.

## Categories

- [Melee Weapons](melee/) (143 weapons)
- [Ballistic Firearms](ballistic/) (125 weapons)
- [Energy and Beam Weapons](energy/) (53 weapons)
- [Magic Implements](magic/) (58 weapons)
- [Shields and Off-Hands](shields/) (28 weapons)

## Documentation Rules

- Use the name-based dossier as the canonical human-readable reference.
- Use the stable weapon ID for code, loot tables, crafting recipes, and manifests.
- Keep category and family indexes as navigation pages rather than duplicate stat stores.
