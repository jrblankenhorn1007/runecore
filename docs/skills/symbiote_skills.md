# Symbiote Class Skill Tree: Bio-Metamorphosis, Tendril Combat, Spores & Parasites

This document specifies all 52 class skills for the **Symbiote (Druid Archetype)** in Untitled RPG. The Symbiote bonds directly with an alien parasitic organism, morphing their anatomy into predatory forms, whipping barbed tendrils, infesting hosts, and controlling nature's fungal mycelium.

---

## 1. Class Identity & Resource Dynamics
- **Core Resource**: Biomass Reserves ($BMS$, 0–100 scale). Harvested by devouring organic corpses, consuming parasitic leeches, and draining life directly from entrapped victims.
- **Morphological Shifts**: Seamlessly transforms between Primal Beast (high DPS/agility), Chitinous Behemoth (immense tankiness), and Spore Swarm (intangible caster).
- **Weapon Proficiencies**: Bio-Tendril Whips, Organic Claws, Bone Scythes, Spore Launchers, Living Seed Staffs.
