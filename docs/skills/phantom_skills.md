# Phantom Class Skill Tree: Stealth, Infiltration, Phase-Dashing & Critical Assassination

This document specifies all 52 class skills for the **Phantom (Rogue Archetype)** in Untitled RPG. The Phantom weaves through shadows, phases through physical matter, applies lethal neurotoxins, and executes fatal precision strikes from stealth.

---

## 1. Class Identity & Resource Dynamics
- **Core Resource**: Shadow Shroud ($SHR$, 0–100 scale). Builds while unseen, crouching in darkness, or executing flawless phase-dodges. Decays when detected in bright light.
- **Stealth & Ambush Mechanics**: Striking from stealth guarantees massive critical strike multipliers and armor bypass.
- **Weapon Proficiencies**: Daggers, Claws, Monomolecular Whips, Suppressed Pistols, Shurikens, Kunai.

---

## 2. Complete Phantom Skill Catalog (52 Skills)
